# Execution Notes — Make QuickList Per-List Installation Explicit and Flicker-Free
**Task**: ./FK40.task.md
**Plan**: ./FK40.plan.md

## Decisions

- Keep the manifest selected by the initial server document fixed for the document lifetime.
- Restrict the QuickList per-list target to `/quicklists/:projectId/install`.
- Use ordinary Next.js links among the project index, list, and info pages.
- Use a native anchor from list info to the installer so that transition deliberately creates the list-specific document.

## Problems Encountered

- The existing project link already used `next/link`; the visible reload came from `ManifestLink` calling `window.location.reload()` after the route changed manifest identity.

## Deviations From Plan

- None.

## Additional Requests

- The operator initially reported the reload as a regression, then confirmed the dedicated installer page and intentional full-document boundary described by this task.

## Known Limitations

- Physical iPhone and Android installation and relaunch checks remain for the operator. Browser automation verified the application-side boundary but cannot complete native install sheets reliably.
