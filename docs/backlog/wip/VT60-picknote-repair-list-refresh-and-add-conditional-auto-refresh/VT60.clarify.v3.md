# Clarify Round v3 — PickNote: Repair List Refresh and Add Conditional Auto-Refresh

## Questions

### 1. Where should the account-wide auto-refresh slider live: on the account/profile settings page, inside each open list, or in both places?

## Answers

### 1.

Put the UI control on the user profile page. Add a QuickList-specific custom profile block, following the existing LingoCafe custom preferences block pattern.

## Resolution Summary

- The control lives on `/profile`, not inside individual lists or list top bars.
- Implement it as an app-owned QuickList custom profile block registered directly in `app.profile.items`.
- Follow the LingoCafe `LingocafePreferences` pattern: central `useProfile()` state, `useProfileBlockHandle()` integration, `profileKeys` ownership, AppConfig schema validation, and the shared profile-page save action.
- Persist through the existing `auth.users.profile` JSON data and `/api/profile` flow, so no schema migration is needed.
