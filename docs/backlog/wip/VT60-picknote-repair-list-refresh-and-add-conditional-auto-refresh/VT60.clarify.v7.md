# Clarify Round v7 — PickNote: Repair List Refresh and Add Conditional Auto-Refresh

## Questions

### 1. How should auto-refresh behave when a phone/app returns to the foreground with a list still open?

## Answers

### 1.

If auto-refresh is set to Slow, Medium, or Fast, immediately check for updates whenever the phone is unlocked or the app/list is reopened in the foreground, even when the normal interval has not elapsed. If auto-refresh is Off, do not run this check.

## Resolution Summary

- Any enabled level performs one immediate conditional refresh when an already-open list returns to the foreground.
- The resume check ignores the remaining interval delay and then restarts the regular schedule.
- Off remains fully manual and does not perform a resume check.
- Mobile/app lifecycle signals must be deduplicated and must not create overlapping requests.
