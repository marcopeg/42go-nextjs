# Clarify Round v4 — PickNote: Repair List Refresh and Add Conditional Auto-Refresh

## Questions

### 1. What should the default auto-refresh level be for an account that has never saved the setting?

## Answers

### 1.

Default to Medium. If no saved information exists, auto-refresh is already active at the Medium interval.

## Resolution Summary

- Missing profile data resolves to `medium` without blocking the account.
- Existing and new accounts begin polling an open list every 10 seconds until they save a different level.
