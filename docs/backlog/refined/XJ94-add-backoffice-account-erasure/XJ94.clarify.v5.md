# Clarify Round v5 - Add Backoffice Account Erasure

## Questions

### 1. Should an operator with `users:delete` be allowed to delete their own account?

## Answers

### 1.

No. It must not be possible for an operator to delete their own account, even if they have `users:delete`. The API must enforce a strong self-delete check server-side.

## Resolution Summary

- Resolved: self-deletion from backoffice is forbidden.
- The delete API must reject attempts where the acting operator user ID matches the target user ID.
