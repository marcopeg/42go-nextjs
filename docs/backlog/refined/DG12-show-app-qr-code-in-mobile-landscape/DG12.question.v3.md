## Questions

### 1. When `qr.url` is missing, should the QR use the current full page URL or only the app root URL?

Answer:
Use the app root URL by default. Also add `qr.pageURL` as a list of regular expressions. If the current full URL matches any expression in `qr.pageURL`, the QR should link to the current full URL instead. LingoCafe should use this so book info pages can be shared by rotating the phone.
