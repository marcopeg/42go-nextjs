# Plan — QuickShare: Establish isolated app, account onboarding, and data model

## Goal

Create the isolated QuickShare application, durable account/resource model, and shared contracts on which every editor, publisher, and automation task depends. Production uses the `quickshare` app identity; local autonomous testing enables the same feature surface in the `default` app while preserving `app_id=default` ownership for seeded users.

## Milestones

### Milestone 1 — Register isolated and locally testable application surfaces

- [x] Step 1 — Add the QuickShare application boundary
  - Achieve: Resolve `quickshare.42go.dev` to a dedicated authenticated app with host-only editor cookies, QuickShare navigation, feature gates, and handle-first onboarding.
  - Create: `src/config/quickshare/` configuration, icon/profile/onboarding components, and protected QuickShare page shell.
  - Modify: `src/AppConfig.ts`, app route/navigation configuration, and any host-cookie configuration required by the existing auth system.
  - Delete: Nothing.
  - Touch points: App resolution, NextAuth request-scoped configuration, AppLayout, profile blocks, feature policies.
  - Validation: App-resolution and policy tests prove the QuickShare hostname selects only `quickshare`; browser checks prove an unauthenticated request is gated and editor cookies are not domain-wide.
  - Notes: Do not create a second auth/session system or share product rows with QuickNotes.

- [x] Step 2 — Enable the same capability in the default development app
  - Achieve: Let seeded `john/john` and `admin/admin` exercise QuickShare locally at localhost without impersonating or aliasing a `quickshare` tenant.
  - Create: Default-app QuickShare menu/profile integration only where a shared component is needed.
  - Modify: `src/config/default/config.ts` to enable QuickShare page/API features and navigation.
  - Delete: Nothing.
  - Touch points: Default AppConfig, seeded default users, shared QuickShare routes.
  - Validation: Login on localhost as both seeded users; verify all created account/resource rows carry `app_id=default` and are invisible from the production QuickShare app identity.
  - Notes: Do not rerun or replace seeds automatically.
