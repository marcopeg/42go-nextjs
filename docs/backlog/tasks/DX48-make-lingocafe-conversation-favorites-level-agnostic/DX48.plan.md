# Plan — Make LingoCafe Conversation Favorites Level-Agnostic

## Goal

Make a conversation favorite durable per learner, semantic variant, and language, so it is shared by all of that variant's eligible CEFR realizations and rendered through the existing Starred route and category-level chooser behavior.

## Milestones

- [x] Step 1 — Replace exact-conversation star keys with variant-plus-language keys

  - Create: A timestamped Knex migration after the conversation baseline.
  - Modify: `docs/lingocafe/CONVERSATIONS_DATA_MODEL.md`; schema-focused tests.
  - Delete: No user or content data. The legacy exact-conversation foreign-key column and its index are replaced only after migrated rows are verified within the transaction.
  - Touch points: `lingocafe.conversation_stars`, `lingocafe.conversation_variants`, `lingocafe.conversations`, user-state version behavior.
  - Validation: Migration SQL proves all legacy rows map before change, preserves earliest timestamps, enforces `(user_id, scenario_id, variant_id, language)` uniqueness and variant ownership, and reverses safely to exact rows only where a matching realization exists.
