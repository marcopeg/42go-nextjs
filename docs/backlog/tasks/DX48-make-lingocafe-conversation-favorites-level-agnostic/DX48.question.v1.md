## Questions

### 1. Which conversation should one favorite represent?

Recommended: one semantic **variant** across all of its language/CEFR realizations. A scenario may have multiple meaningfully distinct variants, so favoriting the whole scenario would merge different conversations.

Answer:

A favorite references one variant in one specific language. It spans all available CEFR levels for that language.
