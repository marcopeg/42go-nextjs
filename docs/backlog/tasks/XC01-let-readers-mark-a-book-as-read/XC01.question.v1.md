# Refinement Questions v1 — Let readers mark a book as read

Answer inline under each question, then return to chat and say `next round`.

## Questions

### 1. Which completion entry points must ship in this task?

Choose any combination of:

- a three-dot menu on each `/books` cover
- a button on `/books/[bookId]`
- a button at the end of the actual last reader page

Answer:

all of them

### 2. Can a reader undo completion?

If yes, say where “Mark as unread” should be available and whether it should preserve the saved page and scroll position.

Answer:

yes, from the 3 dots "mark as unread" and from the book details page

### 3. How should a completed book appear on `/books`?

Specify whether completed books remain in `Catalog`, move into a new `Read` section, or use another grouping. Also describe the visible indicator or label on the cover.

Answer:

there should be a "read" section. for now it could be a section at the bottom of the catalog (we don't have so many books right now) but in the future we will change the organization

### 4. What reading action should a completed book offer?

For both the bookshelf card and `/books/[bookId]`, choose whether the primary action should open the details page, start again from the first page, resume the saved final position, or expose more than one action.

Answer:

open the detail page.

### 5. What should happen when a book is marked read before any progress row exists?

Choose what `page_id` and `progress_bps` should store. For example: the last page at `10000`, the first page at `0`, or another explicit rule.

Answer:

no checks. a user can flag a completed book even if they didn't go through (eg, they read it from kindle)

### 6. Should completion always normalize progress to the end?

State whether setting `completed_at` must also set the last page and `progress_bps = 10000`, or whether completion stays independent from the reader’s saved page and scroll position.

Answer:

no, it's an independent data point, only for organization of the bookshelf. but it shoul emit a "book.completed" event.

### 7. What happens when someone reads a completed book again?

Choose whether opening or scrolling the reader automatically clears `completed_at`, keeps the book completed until an explicit “Mark as unread” action, or follows another rule.

Answer:

no, a user can read a completed book and that will not change teh book's status unless the user exolictly marks is at non-read
