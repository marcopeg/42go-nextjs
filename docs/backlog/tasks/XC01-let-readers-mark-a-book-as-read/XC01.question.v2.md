## Questions

### 1. How should completion be stored when the reader has no progress row?

`books_progress.page_id` currently requires a real page. Choose one:

- change `page_id` to nullable so a completion-only row does not invent reading progress
- store a real page such as the first page as a placeholder
- use a separate completion record instead of `books_progress.completed_at`

Answer:

probably is best to have a dedicated table in lingocafe schema

### 2. What visual indicator should completed covers use?

Describe the cover treatment in the `Read` section, such as a `Read` ribbon, checkmark, muted styling, or a combination. Include any preferred color if it matters.

Answer:

so far, just move the title in the "Completed" section at the bottom of the bookshelf

### 3. What exactly does “Mark as unread” change?

Confirm whether it clears only `completed_at` while preserving the saved `page_id` and `progress_bps`, or specify another rule.

Answer:

It deletes the record of completed book. the book goes back in the "reading" zone if there is a record of progress, or in the shelf if nothing was stored

### 4. Should marking a book unread emit an event?

If yes, provide the exact event name, for example `book.uncompleted` or `book.marked_unread`. If no event is needed, say so.

Answer:

yes. then the two events are:

- book.mark.read
- book.mark.unread

### 5. What should the last-page action show for an already completed book?

Choose whether the completion action disappears, becomes a non-interactive `Read` status, or offers another explicit action. “Mark as unread” will remain limited to the bookshelf menu and details page unless you say otherwise.

Answer:

omit the cta there. it's already marked as completed
