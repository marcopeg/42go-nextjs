# Plan — QuickList: Refresh Open List After Rotation to Portrait

## Goal

Refresh an open QuickList in place when a supported smartphone moves from landscape to portrait, while excluding tablets and desktop browsers and discarding the signal whenever list work is already active.

## Milestones

### Milestone 1 — Define the smartphone orientation contract

- [x] Step 1 — Add testable orientation decisions
  - Achieve: Centralize the existing practical phone-landscape media query and the pure landscape-to-portrait transition decision.
  - Create: No new files.
  - Modify: `src/lib/quicklists/polling.ts`, `tests/quicklist-refresh.test.mts`.
  - Delete: Nothing.
  - Touch points: Smartphone boundary, initial portrait state, portrait-to-landscape state, duplicate/non-orientation changes.
  - Validation: Targeted Node tests prove only a prior qualifying phone-landscape state followed by portrait qualifies.
  - Notes: Use native `matchMedia`; no hook dependency is needed.

  - Create: No new files.
