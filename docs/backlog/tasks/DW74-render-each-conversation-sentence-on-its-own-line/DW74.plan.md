# Plan — Render Each Conversation Sentence on Its Own Line

## Goal

Render each canonical sentence in a conversation round on its own compact line, preserving inline Markdown and keeping translation/playback aligned. The feature remains enabled by one round-level prop that can later be changed in one line.
