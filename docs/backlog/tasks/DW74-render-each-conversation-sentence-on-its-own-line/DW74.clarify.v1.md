# Clarify Round v1 — Render Each Conversation Sentence on Its Own Line

## Questions

### 1. Should consecutive sentence lines use only the reader's normal line height, like a soft line break, or should there be extra vertical spacing between sentences?

## Answers

### 1.

Use normal line height, like a soft line break. Do not add extra vertical spacing between sentences.

## Resolution Summary

- Consecutive sentence lines remain compact and use the reader's normal line height, without paragraph-style spacing.
