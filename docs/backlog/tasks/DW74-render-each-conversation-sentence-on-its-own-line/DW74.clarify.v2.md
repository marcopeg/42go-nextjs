# Clarify Round v2 — Render Each Conversation Sentence on Its Own Line

## Questions

### 1. Should one-sentence-per-line rendering apply only to dialogue text inside conversation rounds, or also to conversation titles and descriptions when they contain multiple sentences?

## Answers

### 1.

Apply it only to dialogue text inside conversation rounds. Conversation titles and descriptions must keep their existing flowing layout. Structure the code so the behavior is easy to activate or deactivate because it may later move into the preference panel.

## Resolution Summary

- Sentence-per-line rendering applies only to conversation round dialogue.
- Titles and descriptions retain their current inline flow.
- The implementation exposes a clean activation boundary suitable for a future reader preference.
