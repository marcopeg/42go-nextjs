# QuickShare: Add a rich web-page editing experience

## Elevator's Pitch

Improve QuickShare web-page authoring with a capable editor experience after the plain-text-area first release.

## Business Gain

Authors can create and maintain richer shared web pages more comfortably without changing the first-release publishing contract.

## Current State

The first QuickShare release provides simple text areas for plain HTML, CSS, and JavaScript.

## Desired State

QuickShare offers an improved web-page editing experience with appropriate editing affordances while retaining the existing durable-draft and explicit-publish model.

## Definition of Success

An author can comfortably create, edit, preview, and publish a web page through the enhanced editor without altering existing drafts or public URL behavior.
