# Add Speaking Feedback and Tap-to-Stop to Reader Translation Pronunciation

## Elevator's Pitch

Improve the LingoCafe reading-page translation popover's one-shot `Play sentence` / `Play word` button so it visibly communicates active speech and acts as a stop control when pressed again.

## Business Gain

- Readers can immediately tell that pronunciation is still playing, even when speech starts slowly or the selected text is long.
- The same compact control provides an obvious way to stop unwanted speech without closing the translation or opening the audiobook player.
- Clear playback feedback makes pronunciation practice feel responsive on both mobile and desktop.

## Current State

- The translation popover is implemented in `src/app/(app)/(lingocafe)/books/_components/BookPageReader.tsx` and delegates isolated pronunciation to `useReaderPlayback`.
- The one-shot action is labeled `Play sentence` or `Play word` according to the active translation scope.
- While pronunciation is active, the button receives a filled treatment and `aria-pressed`, but its label and static play icon do not provide ongoing motion or another clear speaking cue.
- Pressing the active pronunciation button calls the play path again. The current playback logic cancels the utterance and starts it again instead of stopping and remaining idle.

## Desired State

- While isolated sentence or word pronunciation is active, keep the visible `Play sentence` or `Play word` label stable and replace the static play triangle with a small animated three-bar speaking indicator. The button geometry and compact action line must not shift between idle and active states.
- Activate the speaking treatment immediately after the speech request is accepted so device-voice startup delay still receives feedback. Do not imply percentage or duration progress.
- While active, expose `Stop sentence` or `Stop word` as the control's accessible name and preserve an appropriate pressed/active state so assistive technology understands what the next activation will do.
- Pressing the active `Play sentence` or `Play word` button stops that isolated utterance immediately and leaves it stopped. It must not restart the selection, start continuous audiobook playback, dismiss the translation popover, or resume unrelated playback.
- If opening the translation auto-paused continuous audiobook playback, stopping isolated pronunciation leaves the audiobook paused while the popover remains open. Existing popover-dismissal behavior remains responsible for deciding whether to resume it.
- After natural completion, cancellation, stop, or error, remove the speaking indicator and return the button to its normal play state.
- A later press from the idle state starts the selected sentence or word from the beginning as it does today.

## Definition of Success

On mobile and desktop, readers can see when the translation popover is speaking a sentence or word and can stop that pronunciation by pressing the same control once. The visual indicator follows the real speech lifecycle, the popover stays open, and continuous audiobook behavior does not regress.

## Additional Context

This is a focused follow-up to GC03, which introduced the separate one-shot pronunciation action and its filled active state. Reuse the existing reader speech provider and playback controller boundaries. The second `Start audiobook from here` action is explicitly outside this task.

## Assumptions

- This request applies to the LingoCafe book reading page because QuickList has no translation-reading surface.
- Both labels of the same one-shot control are in scope: `Play sentence` and `Play word`.
- The active indicator is an animated three-bar speaking treatment that replaces the static play icon while leaving the visible text label unchanged.
- The active state begins as soon as the provider accepts the speech request, rather than waiting for an audible-start callback.
- The animation should be subtle, fit inside the current compact button, and respect reduced-motion preferences.
- Stopping isolated pronunciation keeps the translation popover open.
- Stopping isolated pronunciation does not resume an audiobook that was auto-paused when the translation opened. Existing popover-dismissal behavior remains authoritative for resume.

## Constraints

- Limit changes to the one-shot pronunciation button and the smallest necessary reader-playback integration.
- Do not change the behavior, label, delay, or styling contract of `Start audiobook from here`.
- Do not expose or open the continuous playback bar for isolated pronunciation.
- Do not allow overlapping utterances.
- Preserve existing translation dismissal, language-selection, speech-capability, analytics-privacy, and auto-pause/resume behavior.
- Use theme-aware styles and preserve keyboard focus, touch targets, screen-reader semantics, and reduced-motion support.
- Run `npm run qa` and verify the behavior through the LingoCafe test tunnel on desktop and near a 390px mobile viewport.
