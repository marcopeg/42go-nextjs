# Execution Notes — Add Speaking Feedback and Tap-to-Stop to Reader Translation Pronunciation
**Task**: ./MR94.task.md
**Plan**: ./MR94.plan.md

## Decisions

- Keep the visible `Play sentence` / `Play word` label stable and reserve a fixed icon slot so active feedback does not move the compact action line.
- Use a route-local three-bar speaking indicator driven by the existing isolated-pronunciation lifecycle state.
- Keep pronunciation lifecycle ownership in `useReaderPlayback`; a small pure model owns click intent and play/stop labels for direct automated coverage.
- Treat any active isolated pronunciation click as stop intent before checking whether a new utterance can start. This makes stop reliable even if voice availability changes while speech is active.
- Preserve translation auto-pause state when isolated pronunciation stops; existing popover dismissal remains the only resume trigger.
- Keep the indicator route-local. The documented reader system already uses equalizer-like feedback, and this change does not introduce a new reusable visual contract.
