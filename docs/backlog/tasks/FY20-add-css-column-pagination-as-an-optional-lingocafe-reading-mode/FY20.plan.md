# Plan — Optional LingoCafe CSS-column pagination

## Goal

Ship experimental, opt-in horizontal reading with local persistence, existing translation/audio, and unchanged vertical mode.

## Authorization

The operator requested “plan and implement”; this authorizes creating and executing this plan together.

## Milestones

### Milestone 1 — Reading mode and pagination foundation

- [x] Add a safe local reading-mode preference and accessible experimental selector for books only.
  - Modify: reader preference store, hook, preferences panel, book reader wiring.
  - Validation: storage defaults, malformed/unavailable storage, theme-independent persistence.
- [x] Add CSS-column layout, geometry helpers, and horizontal support in the scroll-target abstraction.
  - Create: scoped pagination CSS and geometry helpers.
  - Modify: reader surfaces and scroll target.
  - Validation: complete text flow, one column per screen, stable width/height, first/last progress.

### Milestone 2 — Reader integration

- [x] Implement swipe, keyboard, trackpad, and button turns, including seamless chapter boundaries.
  - Preserve: explicit navigation and URL progress precedence; no wrapping or automatic completion.
  - Validation: first/last chapter transitions, selection and overlay gesture discrimination.
- [x] Preserve a content anchor across mode/typography/viewport changes and local reopen.
  - Create: section-keyed anchor with sentence text validation and character offset; reuse legacy progress as fallback.
  - Modify: local scroll memory and restoration, geometry observers.
  - Validation: switching modes mid-paragraph, rotation, reload, stale content and explicit URL override.
- [x] Adapt translation fragment anchors and playback following to paginated geometry.
  - Preserve: sentence IDs, translation APIs, audio continuation, theme and settings surfaces.
  - Validation: targets split across columns and spoken words crossing a screen boundary.

### Milestone 3 — Verification and documentation

- [x] Run focused geometry/preference/restoration regression tests and npm run qa.
  - 27 tests pass; lint and TypeScript pass. Turbopack QA is blocked by worker port binding; native Webpack production build passes.
- [x] Browser-check the localhost reader at mobile and desktop widths, themes, typography changes, navigation, and restoration.
  - Used synthetic API responses with the full reader controller because live-account onboarding requires consent. Later follow-ups verified native Safari and the operator confirmed iPhone reading and voiceover. Standalone PWA checks remain outside this release verification.
- [x] Record validation evidence and any real-device limitations; update task acceptance criteria and execution notes truthfully.

## Scope boundaries

No computed page labels, book totals, EPUB dependencies, profile synchronization, default promotion, or conversation pagination. Use chapter position in the unified paginated toolbar; retain vertical-mode section labels. Preserve unrelated Makefile changes. SE90 remains separate; adapt the reader currently in this checkout without claiming physical Safari browser-chrome verification.
