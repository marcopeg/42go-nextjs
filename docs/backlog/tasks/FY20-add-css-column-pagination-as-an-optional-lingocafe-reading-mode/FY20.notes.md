## Decisions

- Operator authorized planning and implementation together.
- Reading preferences expose Vertical scroll and Paginated (experimental). Only exact local opt-in enables pagination; theme profiles and conversation reading are unaffected.
- CSS columns retain the interactive Markdown tree. A small controller handles button, keyboard, touch and wheel turns without a new dependency.
- The existing scroll-target interface exposes an optional axis; progress and audio consumers share horizontal geometry.
- Local book-position memory includes a sentence/text-offset anchor with text validation. Legacy percentages remain the fallback. In-memory fallback preserves session behavior if browser storage is blocked.
- Preference changes reuse the anchor captured when opening settings to prevent cumulative drift while changing font sizes repeatedly.
- Chapter entry at the last screen is transient state, not a persistent URL percentage that would override later reopening.
- Translation popovers portal into the existing reader surface outside column clipping. Fragment geometry is scoped to the active article.
- Small pure helper modules use explicit relative .ts imports where needed to preserve the existing native Node test runner, without adding a runtime alias loader.
