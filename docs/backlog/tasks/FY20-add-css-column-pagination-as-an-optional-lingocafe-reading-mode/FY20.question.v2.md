## Questions

### 1. Should vertical scroll remain the default until a reader chooses pagination?

Recommendation: yes. Put the Vertical scroll / Paginated selector in reader preferences, remember the selection for all books in the current browser using the existing local preference store, and keep it independent of light/dark theme. Cross-device synchronization is outside this first version.

Existing reader preferences are stored in localStorage by useReaderPreferences.ts, so this follows the current persistence model.

Answer: Yes. The operator confirmed that pagination is experimental and requires explicit activation. Store the choice in localStorage for now. Once the experience matures and confidence grows, it may be promoted to a profile setting and potentially become the default; neither promotion is part of this version. The accepted recommendation places the selector in reader preferences, shares the local choice across books, and keeps it independent of theme.
