# Clarify Round v1 — Choose a Translation Language When Reading and Fluent Languages Match

## Questions

### 1. Which languages should appear in the `Translate to` dropdown?

Should it use the existing fluent-language choices from the LingoCafe profile, excluding the current reading language, or expose a wider set of languages supported by the translation provider?

### 2. What should happen when the reader picks a language?

Should selecting a dropdown option immediately save it as the fluent language and run the pending translation, or should the reader confirm with a separate action such as `Translate`?

## Answers

### 1.

Use the existing fluent-language choices from the LingoCafe profile. Exclude the active reading language. For example, a reader in a Swedish book must not see Swedish as a destination option.

### 2.

Selecting a language is the complete action. Save the selected language to the user's profile as the fluent language, then automatically run the pending translation. Do not require a separate confirmation or `Translate` button.

## Resolution Summary

- The dropdown uses the existing fluent-language choices and excludes the active reading language.
- Selecting a language immediately persists it as `ownLang` and then runs the pending translation.
- No separate confirmation action is required.
