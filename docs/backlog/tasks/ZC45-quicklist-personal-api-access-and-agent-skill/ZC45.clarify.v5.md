# Clarify Round v5 — QuickList Personal API Access and Agent Skill

## Questions

### 1. Should the owner be able to change a list's API-enabled status through the token-authenticated API, or only through the signed-in UI?

## Answers

### 1.

Only through the signed-in UI.

## Resolution Summary

- Per-list API exposure can be viewed and changed only by the owner through the normal session-authenticated list settings UI.
- Token-authenticated endpoints never expose, enable, or disable the per-list API setting.
- Agents can operate on lists already exposed by the owner but cannot change the exposure boundary.
