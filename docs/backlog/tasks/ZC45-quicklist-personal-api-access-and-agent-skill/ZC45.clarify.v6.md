# Clarify Round v6 — QuickList Personal API Access and Agent Skill

## Questions

### 1. Should the skill default to a user-level credentials file with environment-variable overrides?

## Answers

### 1.

Yes, with a structured JSON file capable of storing different credentials for different project contexts.

- When the skill is installed inside a project, it stores and selects the credential under a key representing that project path.
- When the skill is installed globally, it stores and selects the credential under a reserved key such as `_global`.

## Resolution Summary

- Use one user-level, owner-readable credentials JSON file rather than tracked project files.
- Support multiple credential entries in that file.
- Project-local skill installations use the canonical project path as their entry key.
- Global skill installations use `_global` as their entry key.
- Credential selection must be deterministic and must not print raw tokens.
- Exact entry fields and environment-variable precedence remain to be finalized.
