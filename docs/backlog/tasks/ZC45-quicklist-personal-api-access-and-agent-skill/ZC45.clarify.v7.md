# Clarify Round v7 — QuickList Personal API Access and Agent Skill

## Questions

### 1. Should every scoped credential entry store both the API base URL and raw token, with project entries keyed by canonical absolute project path?

## Answers

### 1.

Yes.

## Resolution Summary

- The credentials JSON has a top-level `credentials` map.
- `_global` is the reserved key for a globally installed skill.
- Project-local entries use the canonical absolute project path as the key.
- Each entry stores `baseUrl` and the raw bearer `token`.
- Moving a project changes its scope key and requires configuring the credential again or deliberately migrating the entry.
