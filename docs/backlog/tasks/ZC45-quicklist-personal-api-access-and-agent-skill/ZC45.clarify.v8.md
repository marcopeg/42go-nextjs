# Clarify Round v8 — QuickList Personal API Access and Agent Skill

## Questions

### 1. Should credential setup use a secure two-step terminal flow instead of attempting to open and control a terminal automatically?

## Answers

### 1.

Yes.

## Resolution Summary

- When the selected credential scope is missing, the skill reports one explicit setup command.
- The operator runs that command in a user-controlled integrated or external terminal.
- The setup script prompts for the token using hidden input, validates the required values, updates the correct project-path or `_global` entry, enforces owner-only file permissions, and exits.
- The operator then retries the original skill request.
- Tokens must not be requested through the Codex conversation or passed through an agent-controlled stdin session.
- Automatically opening or closing terminal windows is not part of the portable skill contract.
