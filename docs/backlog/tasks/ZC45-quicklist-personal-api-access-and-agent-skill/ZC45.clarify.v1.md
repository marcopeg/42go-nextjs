# Clarify Round v1 — QuickList Personal API Access and Agent Skill

## Questions

### 1. Should the API also manage sharing—inviting and removing collaborators—or only lists, list settings, and items?

## Answers

### 1.

No sharing in the APIs.

## Resolution Summary

- The automation API covers lists, list settings, and items.
- Collaboration administration is explicitly excluded: no invites, collaborator removal, or other sharing-management endpoints.
- A token may still act on a shared list already visible to its user, subject to the same permissions as the app.
