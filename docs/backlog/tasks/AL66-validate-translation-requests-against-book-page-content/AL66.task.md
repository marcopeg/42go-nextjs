# Validate Translation Requests Against Book Page Content

## Historical Summary

Completed server-side hardening for LingoCafe translation: a translation request may use only text that belongs to the requested book page.

## Durable Outcome and Decisions

The route validates feature/session/page ownership and checks requested source text against stored page content before calling the provider. Configuration gates translation and bounds request length; rejection preserves 400/401/403/404 semantics rather than trusting browser text.

## Validation and Limitations
