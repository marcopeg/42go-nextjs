## Durable Outcome and Decisions

- Treat the operator's "yes and implement" as plan acceptance plus execution.
- Move `NO51` from Drafts to WIP before source changes.
- Store consent/acknowledgement evidence only in `lingocafe.profiles.data`.
- Store consent evidence as readable `consent_{key}` objects with `value`, `date`, `version`, `source`, and `method` subkeys.
- Do not collect IP address, User-Agent, screen resolution, operating system, or fingerprinting-style datapoints by default.
- Add placeholder LingoCafe Terms and Privacy public pages in AppConfig so consent links resolve now, while clearly noting the copy should be reviewed before production.
- Change profile block persistence from parallel to sequential so the required Terms and Privacy block can create or update legal acknowledgement data before language and optional-consent blocks persist.
- Keep server-side validation stricter than the UI: creating or completing a LingoCafe profile without Terms and Privacy now returns a validation error.
