# Clarify Round v1 — Build the Book Questionnaire Player and Remediation Results Experience

## Questions

### 1. Where should the questionnaire run in the reader?

### 2. How should answering move through the round?

### 3. What should happen when the learner leaves or deliberately ends an unfinished round?

## Answers

### 1.

Accepted. Add a dedicated protected page at
`/books/{bookId}/questionnaire`, entered from one secondary action on eligible
book details. A full page gives mobile questions and results enough room,
supports refresh/deep-link resume, and keeps book reading modals separate.

### 2.

Accepted. Show one question at a time with native radio-group
semantics, require an explicit `Submit answer` action, save once, then advance
automatically to the next unanswered question. Do not show correctness, allow
editing, or navigate backward during play; show all remediation only after the
round completes.

### 3.

Accepted. Ordinary navigation or refresh preserves the active
round and resumes it later. An explicit `End round` action opens an accessible
confirmation dialog; confirmation abandons the round and returns to the book.
Completed results offer `Practice again`, which starts the next adaptive round.

## Resolution Summary

- Use a dedicated full-page route with one eligible book-detail entry action.
- Require explicit answer submission, then advance automatically through
  forward-only play without correctness feedback.
- Preserve active rounds on passive exit; require confirmation for explicit
  abandonment and offer another adaptive round after results.
