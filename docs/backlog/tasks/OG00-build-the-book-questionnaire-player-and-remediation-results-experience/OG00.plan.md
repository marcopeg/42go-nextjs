# Plan — Build the Book Questionnaire Player and Remediation Results Experience

## Goal

Turn the adaptive questionnaire service into an accessible, responsive book
practice loop: eligible entry, resumable forward-only play, safe submission,
clear scoring, deliberate answer reveal, and exact navigation back to the book
page that explains each mistake.

## Milestones

- [x] Step 1 — Add questionnaire availability to book details

    non-empty published questionnaire without exposing answer content.
  - Create: A small questionnaire-summary type and mapper.
  - Modify: Reader book loader, client book types, and normalization.
  - Delete: Nothing.
  - Touch points: Active questionnaire/question/learning-item relations and
    the existing book-details endpoint.
  - Validation: The pilot exposes one questionnaire action; books without
    eligible content expose none; no answer key enters book metadata.
  - Notes: Eligibility comes from reader data, never a project-name allowlist.

- [x] Step 2 — Define response guards and UI state boundaries
  - Achieve: Validate service payloads enough to fail safely and isolate

  - Modify: Nothing outside the new questionnaire feature files.
  - Delete: Nothing.
