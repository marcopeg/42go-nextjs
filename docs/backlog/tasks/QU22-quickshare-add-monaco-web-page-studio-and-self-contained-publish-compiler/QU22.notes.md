# Execution Notes — QuickShare: Add plain web-page authoring and versioned asset-bundle compiler
**Task**: ./QU22.task.md
**Plan**: ./QU22.plan.md

## Decisions

- Managed web-page assets are bounded, validated base64 payloads held in the immutable draft-revision JSON document. A publish therefore compiles the exact locked draft snapshot; draft assets are never made available from an unauthenticated editor endpoint.
- Preview runs in an opaque-origin sandboxed `srcdoc` iframe with a restrictive CSP and no parent communication contract. It may run authored JavaScript, but cannot read QuickShare cookies, storage, DOM, tokens, or privileged APIs.
- The compiler accepts only managed `assets/<safe-file-name>` references from HTML/CSS, fingerprints every emitted sidecar, and gives compiler errors a source panel/line/column where source is available. `<base>`, inline styles, CSS preprocessors/imports, TypeScript syntax, package imports, and external assets are rejected in v1.

## Problems Encountered

- Docker Desktop does not bind-mount every host temporary directory into Nginx. The static-origin test creates and removes its disposable publication root inside the repository workspace so the mounted Nginx container sees the generated release.

## Deviations From Plan

- Used immutable draft JSON rather than a separate mutable asset table. This preserves the exact asset snapshot captured by the publisher's existing row lock without adding a second publication race.

## Additional Requests

- Keep the default app usable by its seeded users while all QuickShare data remains request-app scoped.

## Known Limitations

- Web-page managed assets are intentionally bounded to 20 files, 2 MiB each, and 8 MiB total. Upload transport is JSON/base64 because this first version has no generalized upload service.

## Validation Evidence

- `npx tsc --noEmit`, `npm run test:quickshare-foundation`, `npm run test:quickshare-authoring`, `npm run test:quickshare-publisher`, `npm run test:quickshare-web-page`, `npm run test:quickshare-nginx`, `npm run lint`, `git diff --check`, and `npm run qa` passed.
- The generated web-page static test activated a real release, then fetched stable HTML and every hashed CSS/JavaScript/image sidecar through Nginx with immutable cache headers and no `Set-Cookie` response.
- Local default-host `/api/quickshare` returned 401 without a session, while `Host: quickshare.42go.dev` rendered the QuickShare page with 200. No connected browser session was available for the seeded credential walkthrough.
