# Execution Notes — QuickShare: Publish atomic artifacts to an isolated Nginx static origin
**Task**: ./IF14.task.md
**Plan**: ./IF14.plan.md

## Decisions

- Bundles use `quickshare.release/v1`: an `index.html`, exact manifest file list, SHA-256 and byte-size evidence, MIME types, content-hashed sidecars, and validated HTML/CSS local references.
- Immutable files project to `/_quickshare/releases/{appId}/{resourceId}/{releaseId}/...`. Stable public entries are atomically replaced symlinks into a private `.quickshare/entries` namespace, so a stable URL always resolves to one complete release.
- Filesystem changes carry compensating rollback closures. Unpublish/Delete purge first moves routes and immutable artifacts into a private journal, finalizing deletion only after the database transaction succeeds.
- Published-handle rename is coordinated through the same rollback/finalize contract: a database failure restores the former delivery folder before the error returns.
- The default app writes beneath `_development/default`; production `quickshare` alone maps to the Nginx-mounted public root.
- The Nginx origin only serves the exact stable and immutable path forms. It has no proxy fallback, and immutable worker scripts can scope only their own release prefix.

## Problems Encountered

- Nginx regex locations with quantifiers must be quoted. The container syntax test caught this before the HTTP fixture test.
## Deviations From Plan

- Added an explicit Docker volume initialization service because a fresh named volume is root-owned while the application image deliberately runs as UID 1001.

## Additional Requests

- Keep the default application independently testable with seeded users. Its publication root is isolated from the production `quickshare` static origin.

## Known Limitations

- The generic publisher is ready but intentionally has no authoring route yet. YW90, QU22, and HZ42 supply type-specific compilers and call `publishQuickShareRelease` with a completed bundle.
- A later S3/CloudFront adapter can preserve the validated manifest and immutable/stable key model without changing resource URLs.

## Validation Evidence

- `npm run test:quickshare-publisher` passed: manifest validation, CSS references, real temporary-root stage/activate/content update/short-to-custom switch/rollback/purge/finalize flow.
- `npm run test:quickshare-nginx` passed against a real Nginx container: stable fixture delivery, immutable cache policy, constrained service-worker scope, hidden-control 404, and no generic fallback.
- `docker compose -f docker-compose.prod.yml config`, `nginx -t`, `npx tsc --noEmit`, focused ESLint, `npm run test:quickshare-foundation`, and full `npm run qa` passed.
