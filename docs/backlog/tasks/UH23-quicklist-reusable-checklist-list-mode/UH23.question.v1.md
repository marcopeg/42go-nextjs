## Questions

### 1. In Checklist mode, should a checked item remain in its current position, or move below the unchecked items as Todo does today?

Answer:

Checked items follow the existing Todo behavior exactly: checking/unchecking changes no ordering rules; manual order remains manual, and checked items are ordered by most recently checked as today. Checklist mode changes only the bottom bulk action: replace completed-item deletion with `Reset checklist`.
