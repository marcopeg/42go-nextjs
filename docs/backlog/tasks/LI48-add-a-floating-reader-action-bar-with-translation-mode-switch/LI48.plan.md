# Plan — Add a Floating Reader Action Bar with Translation Mode Switch

## Goal

Provide the LingoCafe reader with a transparent three-slot floating action bar, backed by a reusable accessible expandable FAB, so translation scope is quickly selectable opposite voiceover on mobile and beside voiceover on desktop without competing with active playback controls.

  - Achieve: Create a reusable 56 px primary FAB that can either invoke one action or open independently surfaced actions through a typed placement API.
  - Create: `src/components/ui/expandable-fab.tsx`.
  - Modify: none.
  - Delete: none.
  - Touch points: Radix Dropdown Menu, shared Button variants, Lucide icons, semantic popover tokens.
