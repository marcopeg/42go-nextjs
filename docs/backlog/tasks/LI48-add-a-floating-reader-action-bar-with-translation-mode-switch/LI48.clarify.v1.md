# Clarify Round v1 — Add a Floating Reader Action Bar with Translation Mode Switch

## Questions

### 1. Translation control

Should the left control show both modes at once (`Word | Sentence`) so the selected mode is always visible, or should it be one compact button that displays the current mode and toggles on tap?

### 2. Bar surface

Should the bottom bar be one visible shared surface spanning between the left and right controls, or a transparent positioning row whose controls look like separate floating elements?

## Answers

### 1.

Use one FAB button that switches between word and sentence translation modes. The icon must make the mode and switching behavior obvious.

### 2.

Use a transparent positioning bar. Do not render one shared background surface behind the slots.

## Resolution Summary

- The translation control is one circular FAB that switches modes.
- The icon requires deliberate, unambiguous mode semantics rather than a generic translation glyph.
- The three-slot floating bar is a transparent positioning shell with independently surfaced controls.
