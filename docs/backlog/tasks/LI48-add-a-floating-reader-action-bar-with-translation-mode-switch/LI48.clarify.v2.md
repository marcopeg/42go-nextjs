# Clarify Round v2 — Add a Floating Reader Action Bar with Translation Mode Switch

## Questions

### 1. Icon state semantics

Should the FAB show the mode currently active, or the mode that will become active after the next tap?

### 2. Literal cue

May the icon include a literal cue such as `W` for word and a short multi-line sentence mark, rather than relying only on abstract translation icons?

## Answers

### 1.

The initial preference was to show the current mode. During the same clarification, the operator refined the interaction: keep one stable translation icon on the collapsed FAB and expose the current mode with a tick in the expanded action list. This later, more specific interaction supersedes the initial current-mode icon idea.

### 2.

Use a recognizable translation icon, potentially the established large/small character translation symbol. Do not put permanent text inside the collapsed FAB. Tapping it reveals labeled `Translate word` and `Translate sentence` actions, with a tick on the current mode.

## Resolution Summary

- The collapsed FAB uses one stable, recognizable translation icon and represents the translation feature rather than either scope.
- The expanded actions carry the unambiguous mode labels and selected-state tick.
- The main FAB opens the available actions; it does not change translation mode by itself.
