# Clarify Round v3 — Add a Floating Reader Action Bar with Translation Mode Switch

## Questions

### 1. Expanded action surface

Should `Translate word` and `Translate sentence` appear as two separate floating labeled buttons with no enclosing popover card?

### 2. Design-system contract

Should this task also add the reusable expandable FAB primitive and its placement, motion, and accessibility contract to the LingoCafe design-system documentation?

## Answers

### 1.

Yes. Render the choices as separate, large, highly visible floating buttons with no enclosing panel. Keep the main FAB on the solid accent/primary color, but give the expanded actions neutral, theme-aware surfaces so the cluster does not become visually heavy. Use light neutral surfaces in light mode and dark neutral surfaces in dark mode rather than hard-coded white or black.

### 2.

Yes. Promote the expandable/enriched FAB to a standard reusable LingoCafe design-system component and document its interaction contract.

## Resolution Summary

- The intended visual is a speed dial whose independent action buttons emerge from the main FAB toward the top-left.
- The main FAB uses the solid primary/accent treatment.
- Expanded actions are large but visually lighter, using semantic neutral surfaces appropriate to light and dark reader themes.
- The expandable FAB becomes a shared LingoCafe design-system component with documented placement, motion, state, and accessibility behavior.
