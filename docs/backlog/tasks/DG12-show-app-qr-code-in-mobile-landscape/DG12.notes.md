# Execution Notes - Show App QR Code in Mobile Landscape
**Task**: ./DG12.task.md
**Plan**: ./DG12.plan.md

## Decisions

- Accepted plan and transitioned `DG12` to WIP before implementation.
- Added `qrcode.react` and used `QRCodeSVG` for the QR renderer.
- Mounted `AppQrOverlay` inside the shared `Providers` tree so public and authenticated pages are covered.
- Used a media-query-driven phone-landscape detector: landscape, coarse pointer, no hover, `max-width: 960px`, and `max-height: 540px`.
- Resolved QR destinations as explicit `qr.url`, matching `qr.pageURL`, then current origin root.

## Problems Encountered

- `npm install qrcode.react` reported existing audit findings: 1 low, 6 moderate, 1 high, and 1 critical. They were not addressed because this task is not a dependency security cleanup.
- The repo has no permanent browser automation harness, so temporary Playwright was installed under `/tmp/dg12-playwright` for local orientation smoke without changing repo dependencies.

## Deviations From Plan

- Automated helper tests were not added. The repo only has a narrow email-validation node test, and there is no established TypeScript unit-test harness for importing app helpers directly. Browser smoke covered the main behavior instead.
