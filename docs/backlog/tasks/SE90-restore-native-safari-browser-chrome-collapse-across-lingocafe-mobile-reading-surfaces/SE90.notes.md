# Execution Notes — Restore Native Safari Browser-Chrome Collapse Across LingoCafe Mobile Reading Surfaces
**Task**: ./SE90.task.md
**Plan**: ./SE90.plan.md

## Decisions

- Preserve `AppLayout.containedMobileScroll` for unrelated consumers, including Backoffice Users.
- Preserve the desktop Book Reader's Modal and element-level scroll containment.
- Use root-document scrolling below `md` and the existing element scroller from `md` upward.

## Problems Encountered

- The first live overlay check appeared to show a Reader scroll jump. The browser test locator was auto-scrolling the sticky trigger before clicking it. Re-testing with a visible-DOM touch produced a zero-pixel delta across both Preferences and Contents.
- The shared Modal's default focus movement can scroll a document-backed surface. A scoped `preserveDocumentScroll` contract now focuses the dialog and restores the trigger with `preventScroll`, while Reader-specific capture/restoration protects the underlying document through body locking.
- `npm run qa` completed lint with one pre-existing warning, but its Turbopack build could not create a local helper process because this execution environment rejects the temporary port with `Operation not permitted`. Re-running with elevated execution produced the same environmental failure. `npx next build --webpack` compiled successfully, completed TypeScript, generated all 43 static pages, and collected build traces.
- The first pass omitted the individual Conversation Reader. It still rendered inside an always-open `100dvh` Modal with a nested `overflow-y-auto` element, which the operator confirmed with a physical-iPhone Safari screenshot.
- The reported three-row intermediate list used root-document scrolling but exposed only 44 px of scroll range at 390 × 720. That is too short for Safari to fully retract its browser chrome. A speculative removal of the existing horizontal clipping and mobile transition then regressed the previously working root page, so that wrapper change was reverted and only the measured scroll-runway fix remains.
