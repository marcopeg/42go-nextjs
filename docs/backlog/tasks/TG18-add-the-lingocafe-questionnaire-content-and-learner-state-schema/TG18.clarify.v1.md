# Clarify Round v1 — Add the LingoCafe questionnaire content and learner-state schema

## Questions

### 1. Should spaced-repetition memory state belong to a learning item or to an individual question?

### 2. How should binary questionnaire results feed FSRS's four ratings?

### 3. Which published-content identity should historical answers retain?

## Answers

### 1.

Accepted. Store state per user, questionnaire, and learning item. Questions are
retrieval prompts for a concept; future question variants reinforce the same
memory state instead of fragmenting it into separate cards.

### 2.

Accepted. Version one maps wrong to `Again` (1) and correct to `Good` (3), while
storing the applied 1–4 rating so future modes may expose or derive `Hard` (2)
and `Easy` (4) without changing history.

### 3.

Accepted. Keep stable questionnaire, learning-item, and question identities,
publish immutable question revisions identified by a content digest, and make
each round item reference the exact revision and answer set it rendered.

## Resolution Summary

- Scheduler granularity is the learning item, not the individual question.
- Binary grading maps wrong to `Again` and correct to `Good`; the applied FSRS
  rating is persisted for future modes.
- Historical round items retain the exact immutable question revision and
  answer set rendered to the learner.
