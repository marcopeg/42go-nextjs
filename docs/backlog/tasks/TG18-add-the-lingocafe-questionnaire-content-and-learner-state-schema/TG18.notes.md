# Execution Notes — Add the LingoCafe Questionnaire Content and Learner-State Schema

**Task**: ./TG18.task.md
**Plan**: ./TG18.plan.md

## Decisions

- FSRS memory state is scoped to a learning item. Questions are revisioned
  retrieval prompts for that concept.
- Version-one binary grading persists `Again` (1) for wrong and `Good` (3) for
  correct, while the schema accepts all four FSRS grades.
- Historical round items retain the exact question revision and answer set that
  was rendered.

## Problems Encountered

- PostgreSQL truncated Knex's generated foreign-key names, causing collisions;
  the migration now assigns compact explicit names to every long composite key.
- The first version-aware rollback encountered a trigger function that did not
  exist in the previously applied migration. Rollback now uses guarded function
  removal, so incremental development and production rollback are both safe.
