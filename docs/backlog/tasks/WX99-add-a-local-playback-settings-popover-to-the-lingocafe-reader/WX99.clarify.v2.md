# Clarify Round v2 — Add Voiceover Highlight Preferences to LingoCafe Profiles

## Questions

### 1. After Save succeeds, must an already-open reader tab apply the new highlight settings immediately, or may the settings apply the next time the reader loads?

## Answers

### 1.

The profile integration is removed from scope. Playback settings apply immediately in the local app and do not synchronize across readers, tabs, devices, or the user account. The settings live in the player UI and persist in local storage, like reading preferences.

## Resolution Summary

- The task is now a device-local player-settings feature, not a user-profile feature.
- Speed and highlight changes apply immediately.
- Speed plus both highlight toggles persist in local storage.
- No cross-device, cross-tab, database, profile API, or account synchronization is required.
