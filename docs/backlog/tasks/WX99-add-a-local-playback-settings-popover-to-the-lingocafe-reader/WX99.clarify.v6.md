# Clarify Round v6 — Add a Local Playback Settings Popover to the LingoCafe Reader

## Questions

### 1. Should the player settings trigger show only a gear icon, or show a gear plus the current speed such as `1×`?

## Answers

### 1.

Show a gear icon together with the current speed, such as `1×`. Also replace all negatively named disable toggles with positive settings: `Word highlighting`, `Sentence highlighting`, `Auto-pause on translation`, and `Auto-pause on settings`. All four boolean settings default to `true`; missing stored values must also resolve to `true`.

## Resolution Summary

- The settings trigger shows a gear plus the current playback speed.
- All boolean preference names and stored semantics are positive rather than `disable...` flags.
- Word highlighting, sentence highlighting, translation auto-pause, and settings auto-pause all default to `true`.
- Missing or invalid boolean storage values resolve to `true`.
