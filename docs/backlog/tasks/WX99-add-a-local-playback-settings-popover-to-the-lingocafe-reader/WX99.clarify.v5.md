# Clarify Round v5 — Add a Local Playback Settings Popover to the LingoCafe Reader

## Questions

### 1. After the settings popover closes, should playback resume automatically when it had been playing before opening, or remain paused until the user presses Play?

## Answers

### 1.

When settings auto-pause is active, closing the popover automatically resumes playback. If only highlight settings changed, resume the paused utterance from its current mid-sentence position. If speed changed, restart the current sentence at the selected speed. Add two more persisted toggles: `Disable auto-pause on translation` and `Disable auto-pause on settings`.

## Resolution Summary

- By default, opening settings pauses active playback and closing settings resumes it automatically.
- Highlight-only changes preserve the paused utterance position and continue mid-sentence on close.
- A speed change restarts the current sentence at the new speed.
- `Disable auto-pause on translation` lets playback continue when translation is opened.
- `Disable auto-pause on settings` lets playback continue while the settings popover is open.
- Both new disable flags are device-local playback settings and persist in local storage.
