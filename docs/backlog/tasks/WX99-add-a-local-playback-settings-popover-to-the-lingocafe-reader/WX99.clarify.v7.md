# Clarify Round v7 — Add a Local Playback Settings Popover to the LingoCafe Reader

## Questions

### 1. After selecting a speed, should the settings popover stay open so the user can change other options, or close immediately?

## Answers

### 1.

Keep the popover open after speed and toggle changes so the user can change multiple settings in one visit. Provide an explicit close control. Clicking outside the popover must also close it, and clicking the gear/speed trigger again toggles it closed.

## Resolution Summary

- Speed and toggle changes do not close the popover.
- The popover provides an explicit close control.
- Outside click closes the popover.
- Clicking the gear/speed trigger again closes the open popover.
- Closing through any supported path invokes the same accepted auto-resume or current-sentence restart behavior.
