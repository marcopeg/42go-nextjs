# Clarify Round v3 — Add a Local Playback Settings Popover to the LingoCafe Reader

## Questions

### 1. If the user selects a different speed while a sentence is already being spoken, should that sentence restart immediately at the new speed, or should the new speed begin with the next sentence?

## Answers

### 1.

Restart the current sentence immediately at the newly selected speed.

## Resolution Summary

- A speed change during active speech cancels the current utterance and restarts the same sentence immediately at the selected speed.
