# Clarify Round v3 - Add Backoffice Account Erasure

## Questions

### 1. For Quicklist, should deleting a user also delete every project they own, including all tasks and collaborators in those projects?

## Answers

### 1.

Yes. The task includes the Quicklist erasure integration. Deleting a user should delete the user's Quicklist-owned data, including projects they own and the dependent tasks/collaborators/invites for those projects. The task also includes the LingoCafe erasure integration, deleting user-owned reading state such as current chapter/book progress. Event history remains untouched.

## Resolution Summary

- Resolved: Quicklist must provide an account erasure handler that removes the user's Quicklist-owned data, including owned projects and dependent project data.
- Resolved: LingoCafe must provide an account erasure handler that removes user-owned reading state such as current chapter/book progress.
- Event history remains untouched.
