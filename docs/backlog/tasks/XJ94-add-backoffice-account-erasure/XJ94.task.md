# Add Backoffice Account Erasure

## Historical Summary

Backoffice users can erase an account from `/users` after a two-step destructive confirmation. The first confirmation requires typing the target user's email exactly. The second confirmation asks for final approval after the typed email matches. On confirmation, a server-side delete endpoint runs an app-aware account erasure pipeline. Core validates the request, starts the transaction, runs registered app cleanup hooks for the resolved app, then deletes the app-scoped `auth.users` record and relies on verified database cascades where they are correct. The implementation must detect and handle non-cascading references through app-owned cleanup hooks instead of failing with a vague database error.
