# Clarify Round v2 - Add Backoffice Account Erasure

## Questions

### 1. For LingoCafe event history, should account erasure hard-delete the user's events, anonymize them, or keep them as-is?

## Answers

### 1.

Keep event history as-is. Account erasure should delete from the auth/core account surface and run app-specific account cleanup plugins for the current app. Events are historical telemetry and should not be deleted or anonymized by this account deletion flow.

## Resolution Summary

- Resolved: account erasure must leave event history untouched.
- Core deletes auth-owned account data and runs current-app cleanup plugins; event rows remain historical records.
