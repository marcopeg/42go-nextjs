# Execution Notes — Make the LingoCafe Translation-Scope FAB a One-Tap Toggle
**Task**: ./TR73.task.md
**Plan**: ./TR73.plan.md

## Decisions

- Added one shared `TranslationScopeFab` rather than changing the generic `ExpandableFab`. The generic component remains the direct playback FAB and continues to support speed-dial menus for other use cases.
- The shared control is a compact 56 px-high primary pill with the Lucide translation icon and a lowercase visible `sentence` or `word` label.
- One activation changes the scope immediately. The replacement label rolls upward for 180 ms and uses `motion-reduce:animate-none` for reduced-motion users.
- A desktop hover/focus tooltip names the next target mode. The button's accessible label exposes both current and next scope on all viewports.

## Problems Encountered

- `npm run qa` linted successfully with one pre-existing warning in `src/app/(app)/layout.tsx`, but its Turbopack build cannot bind a required local worker port in this environment, including with elevated execution.
- The repository's `npm run build:docker` Webpack fallback cannot load the required darwin/arm64 SWC binary because it sets `NEXT_TEST_WASM=1`; this is an environment/toolchain failure.
- `npx tsc --noEmit` is blocked by existing, unrelated errors in `src/app/api/(lingocafe)/lingocafe/_lib/conversations.ts` from concurrent Conversation-work changes. No TR73 file appears in the reported diagnostics.
- In-app-browser inspection confirms the rendered mobile pill and its accessible `sentence` label. Its modal-reader click driver did not deliver a state update despite successful navigation interactions, so the direct interaction has focused automated source coverage rather than a completed browser click assertion.

## Deviations From Plan

- Used a keyed CSS label-roll animation rather than effect-driven component animation state. React's lint rules reject synchronous state updates inside effects; the keyed animation provides the same visible upward motion with a simpler and lint-clean implementation.
- Follow-up visual correction: the initial pill reused `Button`'s `fab` size, whose `aspect-square` utility constrained it to a 56 px circle and clipped the icon/label. That pill then proved too wide for the conversation reader's CEFR-level navigation. The final control returns to the standard 56 px circle: a prominent Lucide translation icon plus a small, rolling `W` or `S` mode badge. Conversation reader content now reserves 7.5 rem plus the bottom safe area, keeping the CEFR navigation above the fixed controls.
