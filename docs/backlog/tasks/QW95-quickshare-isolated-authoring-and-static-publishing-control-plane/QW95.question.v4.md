## Questions

### 1. How should a user choose between the existing resource types when creating a new resource, and which resource types must be available in version one?

Answer:

Use a split button in the authenticated editor. Clicking `+ New Share` opens a popover listing every currently available resource type. Version one exposes plain text, Markdown, plain HTML/CSS/JavaScript web page, and the maintained guided-template catalog, initially the Linktree-style links template.

API and personal-token creation requests must provide the resource type explicitly. QuickShare must also expose a GET discovery endpoint—documentation as API—that agents can call to learn the currently supported resource types and their available creation and authoring options.
