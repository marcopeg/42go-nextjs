## Questions

### 1. When an already published resource changes from its generated short URL to a custom handle-scoped URL, what should happen to the prior short URL: become unavailable immediately, redirect to the new URL, or remain as an alias?

Answer:

The old short URL must stop working. If a resource was published with its generated short code and the owner adds a custom identifier, the next publish must replace the old stable route with the new handle-scoped route. The publisher must remove or rename the old stable path only after the new route is ready; immutable release bundles remain governed by the retention policy. The inverse also applies: removing a custom ID generates a new random short code, and the next publish replaces the custom route with that new short-code route. A former random code is not restored.
