# Refinement Questions v2 — QuickShare: Isolated authoring and static publishing control plane

## Questions

### 1. In the first release, should every published resource support both a stable short link and an optional handle-based custom URL, or should custom URLs wait for a later release?

Answer:

Implement both forms for every shareable resource: plain text, Markdown, web page, and template instance. Each resource has its own internal UUID and exactly one active public URL. On editor creation, assign a random globally unique short code and preview the resulting final URL. The author may choose an available custom identifier instead; it replaces the short-code URL with the handle-scoped URL and must be unique only within that owner's normalized handle. The API must accept the optional custom ID on resource creation and return the resulting active URL: the custom URL when supplied, otherwise the generated short URL.
