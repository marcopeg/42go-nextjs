# Refinement Questions v1 — QuickShare: Isolated authoring and static publishing control plane

## Questions

### 1. For the first release, should all six milestones remain required—foundation, text/Markdown, static publishing, web-page studio, templates, and automation API—or should any move to a later release?

Answer:

For version one, deliver the foundation, text and Markdown authoring, isolated static publishing, plain HTML/CSS/JavaScript web-page authoring in simple text areas, templates, and automation API. Defer a rich editor and any CSS or JavaScript transpilation to separate second-release tasks.
