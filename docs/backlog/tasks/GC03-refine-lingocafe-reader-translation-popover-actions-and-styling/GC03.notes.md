# Execution Notes — Refine LingoCafe Reader Translation Popover Actions and Styling
**Task**: ./GC03.task.md
**Plan**: ./GC03.plan.md

## Decisions

- Reuse the current reader speech provider for continuous audiobook playback and isolated pronunciation.
- Give continuous audiobook startup its own controller action instead of overloading sentence pronunciation.
- Keep the existing route-local anchored popover because it preserves sentence/word positioning and mobile edge-to-edge behavior.
- Use semantic `--primary` color mixes over the reader background rather than adding a hard-coded LingoCafe color.
- Use one isolated-pronunciation callback parameterized by `sentence` or `word`; analytics retain the existing privacy-safe `audio.play.type` distinction.
- Keep the successful/loading/error content as a semantic dismiss button while leaving the language-selection form non-dismissible.
- Use a route-local `ReaderTranslationAction` instead of extending the shared Button with a reader-specific variant.
- Use compact 28 px neutral reader-foreground links after operator testing showed that primary actions competed with the already primary-tinted popover.
- Put action icons after their labels, align the action row by text baseline with the cache-source marker, and separate the two actions by 16 px.
- Use a neutral inverse reader fill for active listening feedback so the state remains legible without adding more primary color to the tinted popover.
- Drive one-shot active feedback from the speech-provider lifecycle; use press feedback for audiobook startup because that action immediately dismisses the popover.
- Hold the audiobook action's filled feedback for 600 ms before invoking continuous playback and dismissing the popover.

## Additional Requests

- After successful live testing, the operator requested link-style listening actions with a smaller height. Both footer actions now use compact 32 px link styling; audiobook startup remains the slightly stronger label through font weight.
- The operator then requested trailing icons, wider space between the links, baseline alignment with `CL`/`MEM`/`DB`/`API`, and neutral action color against the primary-tinted popover. The route-local action component now owns that contract.
- The operator reduced excess space below the action line; its bottom inset is now exactly 2 px.
- The operator requested filled playback feedback. `Play sentence`/`Play word` now remains filled while isolated pronunciation is active, and `Start audiobook from here` fills before dismissing the popover and starting continuous playback.
- The operator requested enough time to perceive audiobook-start feedback. The action now remains filled for 600 ms before the popover closes and playback starts or resumes; abandoning the popover during that window cancels the pending start.
