### 4. What should happen after one-shot pronunciation?

Proposed behavior for both `Play sentence` and `Play word`:

- Keep the translation popover open so the reader can replay or study the translation.
- Do not open or advance the continuous playback bar.
- If translation auto-paused a running continuous session, keep that session paused while the popover remains open and resume it only when the popover is dismissed.
- If playback was already manually paused, keep it manually paused after dismissal.
- If no continuous session existed, return to idle after pronunciation.

Because browser speech has only one active utterance, resuming an interrupted sentence may restart that sentence from its beginning.

Please accept or change this state behavior.

Answer:

accept
