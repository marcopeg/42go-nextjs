# Plan — Add Device TTS Playback to the LingoCafe Reader

## Goal

Add page-local, sentence-by-sentence device TTS playback to the LingoCafe reader with exact-language voice gating, replaceable speech-provider boundaries, sentence and best-effort word highlighting, guided viewport scrolling, explicit playback seeking, translation compatibility, per-sentence analytics, and responsive floating controls.
