## Durable Outcome and Decisions

- Keep one playback controller in the route and pass view state into both responsive reader surfaces.
- Treat normalized primary language matches such as `sv` and `sv-SE` as the same language, while rejecting voices from a different primary language.
- Use the existing client event queue for one `audio.play` event whenever an utterance reaches its start callback.
- Build the sentence catalog from rendered sentence spans and their nearest block element so paragraph pauses follow the actual reader DOM.
- Keep translation state local to `BookPageReader`; sentence activation is also reported to the route-level playback controller.
