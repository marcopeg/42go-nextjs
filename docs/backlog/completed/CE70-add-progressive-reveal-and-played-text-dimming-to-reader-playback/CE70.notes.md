# Execution Notes — Add Progressive Reveal and Played-Text Dimming to Reader Playback
**Task**: ./CE70.task.md
**Plan**: ./CE70.plan.md

## Decisions

- Keep both new booleans in the existing `lingocafe.reader.playback-preferences.v1` record. Field-level sanitization makes the extension backward compatible without a storage-key migration.
- Derive played/current/future presentation from the existing rendered sentence order and active sentence ID. No playback-history state is added.
- Use reversible DOM presentation changes at the reader article boundary so later structural content becomes invisible together with later sentence content while keeping full-page geometry.
- Preserve guided scrolling by committing the new active sentence before measuring it on the next animation frame. This lets the layout frontier reveal the target before scroll positioning runs.
- Preserve the complete reader geometry with CSS `visibility: hidden` for future branches and reuse the canonical sentence-centering path. Progressive reveal has no scroll implementation or dynamic padding of its own.

## Problems Encountered

- The first focused TypeScript run caught the modern DOM type for `HTMLElement.hidden`, which may be `boolean` or `"until-found"`. The restoration snapshot now preserves the full native property type.
- Source review found that guided scrolling originally measured the next sentence before the progressive frontier could reveal it. Centering now runs on the next animation frame after the active index update.
- Real-phone testing showed that standard sentence-centering still fought the collapsed progressive-reveal layout. Reveal mode now bypasses that path and controls its own bottom-pinned position.
- A custom animation-frame scroll loop introduced persistent mobile up/down flicker. It was removed in favor of the browser-native smooth-scroll API.
- Native smooth scrolling still flickered because every frontier update collapsed and rebuilt the page height. The final approach keeps future content measured but invisible and removes all reveal-specific scrolling.
