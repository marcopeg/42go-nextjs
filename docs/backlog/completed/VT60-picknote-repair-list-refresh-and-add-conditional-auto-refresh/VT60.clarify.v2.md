# Clarify Round v2 — PickNote: Repair List Refresh and Add Conditional Auto-Refresh

## Questions

### 1. Should the account have one auto-refresh level for every list, or remember a different level for each list?

## Answers

### 1.

Use one account-wide auto-refresh level for every list. It applies only while an individual list is open. On the lists overview, do not auto-refresh; provide a working manual refresh there as well.

## Resolution Summary

- One account-wide auto-refresh level controls every individual list.
- Scheduled polling runs only while an individual list detail page is open.
- The lists overview never auto-polls, regardless of the account setting.
- Both the individual list page and the lists overview require reliable manual refresh actions.
