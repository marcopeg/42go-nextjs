# Clarify Round v5 — PickNote: Repair List Refresh and Add Conditional Auto-Refresh

## Questions

### 1. Should an explicit manual refresh always download the full authoritative data, while automatic polling uses the lightweight conditional check?

## Answers

### 1.

Yes. Manual refresh should always download the full authoritative data; automatic polling should use the lightweight conditional check.

## Resolution Summary

- Explicit manual refresh bypasses conditional request tokens and forces a complete authoritative payload.
- Scheduled polling uses the conditional ETag/304 path to minimize transfer and rendering work.
