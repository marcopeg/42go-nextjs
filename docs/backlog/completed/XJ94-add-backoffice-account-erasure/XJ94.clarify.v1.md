# Clarify Round v1 - Add Backoffice Account Erasure

## Questions

### 1. What should happen if the user owns or created Quicklist data that currently blocks deleting `auth.users`?

## Answers

### 1.

The deletion procedure should let specific apps register their own cleanup logic. Quicklist should provide the logic to delete Quicklist data for that user. LingoCafe should do the same for LingoCafe-owned data. The core account deletion flow should behave like a small plugin system that runs registered functions during deletion.

## Resolution Summary

- Resolved direction: account erasure should be a core server-side pipeline with app-owned cleanup hooks.
- Quicklist and LingoCafe should register their own cleanup handlers instead of forcing core account deletion to know every app schema.
