# Clarify Round v6 - Add Backoffice Account Erasure

## Questions

### 1. Should admin-initiated account deletion be logged as an event?

## Answers

### 1.

Yes. A deletion performed by an admin must be logged as an event. The event should describe who got deleted, such as target user ID and maybe email, but it does not need to contain the deleted data.

## Resolution Summary

- Successful admin account deletion must write an audit event.
- The event should identify the deleted account with minimal data, such as user ID and email.
- The event must not include full deleted account data or app-owned deleted payloads.
