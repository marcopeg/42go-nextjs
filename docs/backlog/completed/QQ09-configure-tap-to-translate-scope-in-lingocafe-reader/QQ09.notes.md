# Execution Notes — Configure Tap-to-Translate Scope in LingoCafe Reader
**Task**: ./QQ09.task.md
**Plan**: ./QQ09.plan.md

## Decisions

- Translation scope is stored locally as a reader-level preference and is independent of the light, dark, and system appearance profiles.
- Sentence mode remains the fallback/default.
- Word mode highlights only the tapped word.
- The existing reset action continues to reset theme-specific appearance preferences only; it does not reset the theme-independent translation-scope choice.

## Problems Encountered

- The profile settings use an inline semantic tablist/segmented-control pattern rather than a Radix Tabs component. The reader uses that same pattern.
- The configured `https://lc42go.ngrok.app/` reader test endpoint returned `ERR_NGROK_3200` because it is offline, so an authenticated visual smoke could not run.

## Deviations From Plan

- No API route change was needed: the existing endpoint accepts a valid individual word and retains formal validation, profile-language checks, page-membership validation, and cache behavior.
- The initial stock Tabs implementation and its new dependency were removed after visual review because they did not match the profile settings. The Translation and Done sections no longer add inconsistent horizontal dividers.
